# Accessibility

Addressing accessibility as a first-class principle improves your capacity to anticipate, include, and respond to the needs of a wide diversity of individual abilities, empowering you to craft for everyone, with everyone.
<br/>


### `A11yManager`

The `a11y` prop centralizes all accessibility features and provides a simplified and standardized cross-platform surface to streamline how you approach digital access. Your developer experience is further enhanced by the `A11yManager.register()` API that isolates the props away from the render function and gives you type checking and suggestions.

```tsx
import { A11yManager } from '@lucidjs/web';

const a11y = A11yManager.register({
  button: {
    role: 'button',
    label: 'Submit form',
  },
});
```
