# Text

Text displays styled body text with support for nesting, styling, and presenting exactly as it is written in code. It offers pre-configured `variant`s built from your theme that use a blend of semantic-hierarchy types to simplify how you determine their roles.

## Add a custom font
As stated earlier, the design system includes a set of custom fonts to encourage you to provide a consistent experience across platforms. To add custom fonts into your project, add the primitive asset binaries to your local `assets/fonts/`, change your typography tokens to match the names of the asset files, and head on over to the terminal and run the following command:

```bash
npx lucidjs update fonts --web
```

---
### Nesting

`<Text>` only supports nesting other `<Text>` elements. In this case, the nested elements flow like inline text and wrap to avoid overflow.

  of={ TextStories.TextNested }

      </Text>
